# Auto Parry Script

This script enables automatic parrying in Roblox games. Place the script in the `StarterPlayerScripts` folder to ensure it runs for each player when they join the game.

## Install

1. Open your Roblox Studio project.
2. Navigate to the `StarterPlayerScripts` folder.
3. Create a new script and name it `AutoParryScript`.
4. Copy the contents of `AutoParryScript.server.lua` into the script.
5. Create another script in the `StarterPlayerScripts` folder and name it `AutoParryUI`.
6. Copy the contents of `AutoParryUI.client.lua` into the script.

## Use

1. Start the game in Roblox Studio.
2. A UI will appear with a button labeled "Auto Parry: OFF".
3. Click the button to toggle auto parry on or off.
